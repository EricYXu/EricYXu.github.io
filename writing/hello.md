Every notebook begins with the same small hesitation: the first page is too clean, and whatever goes on it seems to set the terms for everything after. This is a page to get that out of the way.

Pieces here are written in plain Markdown. A file dropped into `writing/posts/` becomes an entry in the contents; the few lines at the top of the file give it a title, a subtitle, and a date. Everything else is just text.

## What goes here

Mostly essays and notes, some about research, some not. Nothing is promised to be finished.

> The best way to keep a notebook is to be a little careless with it.

Delete this file whenever the first real piece is ready.
